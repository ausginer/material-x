## So a transformer trait's fields are already exempt from TS2610 and TS2611 today: `Omit` is a mapped type, so its
## properties carry CheckFlags.Mapped (the checker branch quoted in rf54-mapped-brand-probe.txt, part F). Here the
## exemption hides a real hazard: `x` is a class field of the transformer's subclass, so it is an own property of
## every instance, and it shadows `Sub`'s accessor at runtime. RF-54's mapped `Branded` doesn't create this gap and
## doesn't widen it. It changes the exemption only for attribute traits, whose fields are declared as type literals
## and installed as prototype accessors.
