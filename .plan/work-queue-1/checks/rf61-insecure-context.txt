# Reading. Over plain HTTP from a host other than localhost, isSecureContext is false in all three engines,
# crypto.randomUUID is undefined, and calling it throws a TypeError. crypto.getRandomValues exists and fills its
# array in both contexts. createContext() calls crypto.randomUUID() (core/src/controllers/useContext.ts:33-35), and
# button-group-context.ts:25 calls createContext() at module evaluation, so on such a page the module throws and
# every module that imports it fails to evaluate. That last step was read in the code, not run.
