## StoreFilename (lines 3457-3461) is <name>_<version>_<arch>.<ext>, quoted. A fetch made with
## Dir::Cache::archives set to the directory leaves each archive under that name.
## A .deb named on the command line has a file: URI (Desc.URI = Index->ArchiveURI(...)),
## and it is queued like any download unless the check above finds it.
