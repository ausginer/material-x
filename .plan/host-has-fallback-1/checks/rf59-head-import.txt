# The page. A local server streams <head> at once and </head><body><mx-text-field></mx-text-field></body> after
# hold ms. The head declares its charset and is over 1024 bytes, so no engine waits to sniff the encoding (a first
# run without them showed Firefox and WebKit parsing nothing until the body arrived; that run is not used). An import
# map maps @ydinjs/core/ to the built core. An inline classic script records window errors, and import() rejections
# through __rec, with whether document.body existed at that moment. After load (+300 ms): defined = whether the
# module's customElements.define ran; upgraded = whether the page's <mx-text-field> has a shadow root.
#
# The scenarios, each placed in <head>:
#   module-src                 <script type="module" src=text-field.js>          (deferred by default)
#   module-src-async           the same with async
#   module-inline(-async)      <script type="module"[ async]>import '…text-field.js'</script>
#   classic-dynamic-import     <script>import('…text-field.js')</script>          (and the same for list-item.js)
#   classic-bundle             <script src=text-field.iife.js>, rolldown's IIFE bundle of text-field.js and its graph
#   classic-bundle-defer       the same with defer
# hold=1500 stands for a document whose body arrives after the module graph has loaded: a streamed or slow document,
# a long head, or modules already in the cache. hold=0 sends the whole document at once.
