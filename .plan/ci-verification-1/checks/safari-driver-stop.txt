## Why, in the installed packages
node_modules/safaridriver/dist/index.js keeps one driver per Node process:
let instance;
let instancePort;
export const start = (options = {}) => {
        throw new Error(`There is already a Safaridriver instance running on port ${instancePort}!`);
    }
    // spawn, not execFile: execFile buffers the output and kills the driver after 1 MB of it

node_modules/@vitest/browser-webdriverio/dist/index.js, the provider's close(): it deletes the WebDriver session and doesn't stop the driver process that webdriverio started:
	async close() {
		debug?.("[%s] closing provider", this.browserName);
		this.closing = true;
		const browser = this.browser;
		const sessionId = browser?.sessionId;
		if (!browser || !sessionId) return;
		await browser.deleteSession();
		browser.sessionId = void 0;
		this.browser = null;
	}
