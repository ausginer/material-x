## Reading
# A spread calls the array's iterator, so a bundler removes a dead spread only where it can prove the call harmless.
# esbuild kept every array spread in these graphs, even a spread of a local literal.
# rolldown removed a dead spread of an array declared in the same module, and of an imported array whose module
# nothing else keeps in the bundle (then the whole module goes). It kept the spread, and the array with it, when the
# array is imported from a module that stays in the bundle: moduleLive, moduleLiveDecl, liveElsewhere, and the chain.
# Each material-x list spreads a base list imported from a module its entry keeps anyway: ButtonCore.ts (useButtonCore,
# BUTTON_ATTRS), SwitchCore.ts (useSwitchCore, or its own spread), ListItemCore.ts (useListItemCore). So rolldown keeps
# every one of them.
# material-x's own library build (tsdown, which is rolldown, unbundled) exports the lists between modules, so it keeps
# their spreads and emits them as bare statements ([...BUTTON_CORE_TRAITS];) in the published modules. Every consumer's
# bundler, and a browser loading the modules unbundled, starts from those statements.
# An array literal of identifiers, with no spread, is removed by both bundlers when nothing reads it: the variant in
# rf63-reading.txt has no surviving trait list in either bundler.
