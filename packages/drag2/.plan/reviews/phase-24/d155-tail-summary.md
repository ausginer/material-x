What all four passes converged on instead is **one recurring shape of drift**: the commit rewrote the hub sentence — a ledger row, a section header, the paragraph directly beside a code sample — describing what D-155 changed, but left a nearby dependent sentence, table row or code sample **on the same page, sometimes touching the exact same hunk**, still asserting the retired mechanism as current. Nine of the eleven findings below are this one shape, independently reached by three different lenses reading three different files. This is worth naming because it is the identical failure mode the D-165 doc arc (F-232 through F-252, closed the prior round) diagnosed and closed for a different decision — recurring here, in a different commit, against a different decision, in miniature. No new finding is minted for the pattern itself; it is evidence for a scope decision below, not a defect of its own.
