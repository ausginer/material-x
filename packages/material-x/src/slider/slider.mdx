# Slider

## Summary

<SummaryOrWarning summary={summary} tag={TAG} />

## When to use

- Use for a value from a range, such as volume or brightness, where the effect is seen at once.
- Use where the approximate position matters more than the exact number.

## When not to use

- For an exact number, which a text field takes better.
- For a choice between a few options, which a button group or radios present better.

## Value and events

- **The value is the user's.** The handle follows the pointer and the keyboard by itself, and `value` reads the current number. Set `value` at any time, also in an `input` handler during a drag. Setting it fires no event.
- **The `value` attribute** is the initial value. The slider follows it until the user moves the handle or a script sets `value`, and takes it again on a form reset.
- **`value`, `min`, `max` and `step`** give the same result in any order.
- **`input`** fires at each move and **`change`** when the user commits the value. Both are plain events: read `value` from the element.
- If an `input` handler rewrites the value, take the final value from `input`. WebKit then fires no `change`.
- **A touch that becomes a scroll** restores the value, and fires `input` again if it changed.

## Validation

- `setCustomValidity(message)` makes the element invalid. It has no native validators.
- Set `error` rather than `aria-invalid` on the host. It matches `:state(error)` and announces the control as invalid. It draws no error appearance.
- A slider always has a value, so `required` has no meaning for it.

## Accessibility

- **Name:** Use the `label` slot or a `<label>`. If several sources are present, the order is a host `aria-labelledby`, the slot, a host `aria-label`, a `<label>`.
- **`aria-label` on the host** also names the host's own accessible node, so some assistive technology may meet the name twice. Don't use it with the slot or a `<label>`.
- **A late `<label>`:** A `<label>` or a referenced element that appears after the slider is read when the slider takes focus.
- **Keyboard:** The native range's keys. In WebKit the horizontal arrow keys don't mirror from right to left: `ArrowRight` increases the value there.
- **Value:** `valuetext` is announced in place of the number. A host `aria-valuetext` replaces it for assistive technology only.

- Keep the label short.
- Give the bounds in the label or beside the slider if they aren't obvious.

## Anatomy

- `label` slot: the slider's name.
- `impl` CSS part: the internal native range, which is transparent.
