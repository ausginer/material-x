## The landing layout

A trace with stacks ([`2026-11-06-landing-layout-trace.txt`](2026-11-06-landing-layout-trace.txt), script [`landing-layout-trace.ts.txt`](landing-layout-trace.ts.txt)) gives layouts per landed cycle:

| Variant                                          | Layouts |
| ------------------------------------------------ | ------- |
| Production                                       | 8       |
| Prototype                                        | 7       |
| Production, landing started before focus restore | 7       |
| Production, no elevation animation               | 8       |
| Production, no kernel focus, consumer refocuses  | 7       |
| Production, no kernel focus, no refocus          | 7       |

**Cause:** the kernel's `focus()` forces a layout, and starting the flight then dirties layout again, so rendering needs one more. Elevation is not the cause.

**The only removal found reorders DRI-9's steps 6 and 7, so production keeps the contract's order and returns this to the architect.** The cost measured is one layout per landed drop. Time spent in layout at 2,000 items is 6,665 µs per cycle against 6,140 µs and 5,506 µs, and the control's own range is 4,810 to 7,457 µs.

- **The +9,208 B doesn't scale with operations.** Production is below the prototype at 0, 400 and 600. The 100, 400 and 600 rows are one round each, from temporary copies of the instrument.
- **From 100 to 400 operations, no `object` or `closure` total grows in the snapshot diff.** Native tables grow 31,944 B, including 52 each of `LargestContentfulPaint` and `InteractionContentfulPaint`, and optimized code grows 27,012 B.
- **Prototype to production at 100 operations** is 10,640 B of code, with `closure` and `object` totals within 144 B.
- The `WeakRef` tests in `tests/destruction.browser.test.ts` separately show no retained item, behavior or view.
- **Conclusion:** no growth attributable to library objects. The difference is compiled code and engine tables.

## Limits

- CDP metrics are Chromium only, headless, with no real compositing cost. Firefox and WebKit have no equivalent here.
- `(root)`, `evaluate` and similar names in the bytes rows are harness or injected code, and read about the same in every arm.
- Physical touch and pen are unverified.
